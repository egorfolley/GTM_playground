# Growth Goaled Snapshot

A single-file Streamlit MVP for a Series A GTM diagnostic demo.

The app uses hardcoded mock company data, calculates raw GTM pillar scores in pure Python, sends the metrics and scores to Claude through the direct Anthropic SDK, parses the response into a `DiagnosticOutput` dataclass, and renders an investor-ready diagnostic UI.

## Information Flow

1. **Start with a realistic company snapshot**

   The demo uses a fictional Series A fintech SaaS company:
   `$6M ARR`, strong top-of-funnel, decent win rates, slower growth, and CAC payback above 18 months.
2. **Add the operating metrics a founder would care about**

   The app includes realistic mock numbers such as pipeline volume, qualified pipeline, win rate, sales cycle, ACV, number of AEs, number of SDRs, and founder involvement in deals.
3. **Score the business across three GTM health areas**

   The app calculates three simple scores:
   Sales Efficiency, Funnel Efficiency, and Founder Dependency.
4. **Ask Claude to interpret the situation like a CRO**

   Claude reviews the company snapshot and the scores, then turns them into clear business insights.
5. **Show the founder what is slowing growth**

   The app explains whether the issue is demand, pipeline quality, ACV, sales process, founder dependency, or hiring timing.
6. **Give a ranked fix order**

   The output tells the founder what to fix first:
   improve pipeline quality, adjust ICP/ACV, then pause hiring.
7. **Turn the diagnosis into a 90-day operating plan**

   The final page gives a practical roadmap, weekly rhythm, and board narrative the founder can use immediately.

## What It Shows

- Home page with a deck-style hero and mock signal feed
- Analysis page with three GTM pillar scores
- How It Works page that explains the agent logic in plain English
- Plotly peer benchmark comparison charts
- CRO-level key insights generated by Claude
- Ranked Fix Order:
  1. Improve pipeline quality
  2. Adjust ICP/ACV
  3. Pause hiring
- 90-Day Execution Roadmap
- Weekly rhythm checklist
- Copyable board narrative
- PDF export button for a simple board-ready download

## Setup

Create a virtual environment:

```bash
python3 -m venv .venv
```

Install dependencies:

```bash
.venv/bin/python -m pip install streamlit plotly pandas anthropic
```

Add your Anthropic API key in `.env`:

```bash
ANTHROPIC_API_KEY=your_key_here
```

The app also supports `st.secrets["ANTHROPIC_API_KEY"]` or a shell environment variable.

## Run

```bash
.venv/bin/streamlit run app.py
```

Then open:

```text
http://localhost:8501
```

## Notes

- The app uses only mock data.
- There are no user inputs, file uploads, or forms.
- Claude is called directly with the Anthropic SDK using `claude-sonnet-4-20250514`.
- If no API key is available, the app displays deterministic preview output so the demo still loads.
