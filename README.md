# Growth Goaled Snapshot

A Streamlit app for a Series A GTM diagnostic demo. Pick one of three pre-built company scenarios (or enter your own numbers), and the app scores the business across three GTM health pillars, sends the data to Claude via the Anthropic SDK, and returns a CRO-level diagnosis with a ranked fix order, 90-day roadmap, and board narrative.

## Information Flow

1. **Select a company scenario**

   Choose from three pre-built use cases or enter founder data in the sidebar. Each pre-built scenario ships with its own company profile and matching industry market data.

2. **Load company and market context**

   The app loads the company's operating metrics (ARR, pipeline, win rate, CAC payback, founder dependency, hiring plan, etc.) alongside category benchmarks specific to that scenario's vertical and stage.

3. **Score the business across three GTM health pillars**

   Pure Python calculates three scores (0–100):
   - **Sales Efficiency** — growth quality, CAC payback, ACV, rep load
   - **Funnel Efficiency** — qualification rate, conversion through the funnel, sales cycle length
   - **Founder Dependency** — how much revenue relies on the founder to close deals

4. **Send everything to Claude**

   The company profile, pillar scores, and market context are sent to Claude with a CRO-in-residence system prompt. Claude returns structured JSON.

5. **Parse and render the diagnosis**

   The app parses Claude's response into a `DiagnosticOutput` dataclass and renders: executive summary, detected situation, key insights, ranked fix order, 90-day roadmap, weekly rhythm checklist, and a copyable board narrative.

6. **Export**

   A PDF export button generates a board-ready download from the current diagnosis.

## Demo Scenarios

| Scenario | Company | Core risk |
|---|---|---|
| UC1: Wrong AE hire risk | $3M ARR Fintech, founder closing all deals, about to hire 2 AEs, no SDR, pipeline coverage 1.8x | Scaling closing capacity before the sales motion is repeatable |
| UC2: Growth stall diagnosis | $6M ARR Healthtech, strong top-of-funnel, CAC payback 19 months, 70% outbound source mix | High pipeline volume not converting; CAC pressure from outbound-heavy mix |
| UC3: Series B defensibility | $9M ARR Fintech, preparing for Series B in 9 months, metrics okay but narrative weak | Board narrative and burn multiple not yet Series B-ready |

Each scenario has its own market data — category benchmarks, competitor hiring signals, and VC sentiment — matched to its vertical and stage. The "Enter your own data" path falls back to generic B2B SaaS benchmarks.

## What It Shows

- Home page with a deck-style hero and mock signal feed
- Sidebar scenario selector with three demo use cases plus founder-entered data
- Sidebar market context panel with category-specific benchmarks per scenario
- Analysis page with three GTM pillar scores and a peer benchmark chart
- CRO-level key insights and ranked fix order generated by Claude
- 90-Day Execution Roadmap with three operating windows and success metrics
- Weekly rhythm checklist
- Copyable board narrative
- How It Works page that traces the full agent logic in plain English
- PDF export for a board-ready download

## Project Structure

```text
app.py                          Streamlit entrypoint and page coordinator
growth_goaled/config.py         Shared constants (model name, etc.)
growth_goaled/models.py         Dataclasses: CompanyProfile, PillarScores, DiagnosticOutput
growth_goaled/mock_data.py      Three pre-built company profiles, each with matching market data; custom company builder; generic fallback market data
growth_goaled/scoring.py        Pure Python GTM pillar scoring logic
growth_goaled/diagnostics.py    Claude API call, payload builder, JSON parser, fallback output
growth_goaled/ui.py             Streamlit page and chart rendering
growth_goaled/styles.py         App CSS theme
growth_goaled/export.py         Dependency-free PDF export builder
growth_goaled/logging_utils.py  Terminal logging helpers
```

## Setup

Create a virtual environment:

```bash
python3 -m venv .venv
```

Install dependencies:

```bash
.venv/bin/python -m pip install streamlit plotly pandas anthropic
```

Add your Anthropic API key in `.env`:

```bash
ANTHROPIC_API_KEY=your_key_here
```

The app also supports `st.secrets["ANTHROPIC_API_KEY"]` or a shell environment variable.

## Run

```bash
.venv/bin/streamlit run app.py
```

Then open:

```text
http://localhost:8501
```

Or online:
```text
https://gtmplayground-njdhknfghmxi36smrjgato.streamlit.app/
```

## Notes

- The app uses only mock data.
- Claude is called directly with the Anthropic SDK using `claude-sonnet-4-20250514`.
- If no API key is available, the app displays deterministic preview output so the demo still loads.
- The "Enter your own data" sidebar form accepts founder inputs and generates a custom diagnosis using generic B2B SaaS market benchmarks.
